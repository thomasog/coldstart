# Privacy

coldstart has no server, account or telemetry, and it collects nothing.

What you tell your agent during setup, such as a project's goal or people's names, is written only to files inside your own folder. coldstart doesn't send those files anywhere. It opens no file outside the folder; it only checks whether a parent folder is a git repository.

If you say yes to model routing for an agent other than Claude Code, your agent opens that tool's public documentation page to read its current format. Nothing from your folder is sent there.

The AI agent you use processes what you share with it under its provider's terms.
